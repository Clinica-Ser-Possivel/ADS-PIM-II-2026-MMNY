# ADS-PIM-II-2026-MMNY
PIM II - Sistema de cadastro de pacientes e prontuários da Clínica Ser Possível

Este repositório contém a documentação técnica e o código-fonte do Projeto Integrado Multidisciplinar (PIM II), desenvolvido como trabalho acadêmico por estudantes do primeiro semestre do curso de Análise e Desenvolvimento de Sistemas (ADS) da UNIP — Universidade Paulista (Campus São José dos Campos). O objetivo do projeto é estruturar a base e o desenvolvimento da aplicação em Linguagem C para a **Clínica Ser Possível**, uma instituição fictícia voltada para o atendimento psicológico e de saúde mental infanto-juvenil. A solução foi concebida para centralizar a gestão da clínica, permitindo o cadastro de pacientes e dos seus respetivos responsáveis legais, além do agendamento de consultas com validação de conflitos de horário. O seu foco principal reside no módulo de Prontuário Eletrônico, projetado com controlo estrito de permissões (via matrícula e senha) para garantir a separação entre as anotações clínicas privadas dos psicólogos e a evolução técnica oficial dos pacientes, assegurando total conformidade com as normas éticas do Conselho Federal de Psicologia (CFP) e com as diretrizes da Lei Geral de Proteção de Dados (LGPD).
