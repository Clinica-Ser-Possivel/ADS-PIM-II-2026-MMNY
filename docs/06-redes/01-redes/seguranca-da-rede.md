# Segurança da Rede

A clínica lida com dados pessoais e sensíveis de crianças e adolescentes, então a segurança é prioridade.

## Medidas básicas

1. **Firewall** no roteador, liberando só o que é necessário.
2. **Redes separadas:** o Wi-Fi dos visitantes fica isolado da rede dos funcionários.
3. **Senha forte no Wi-Fi** (WPA2 ou WPA3), trocada de tempos em tempos.
4. **HTTPS** em todo acesso ao sistema, para proteger os dados enquanto trafegam.
5. **Login individual** para cada pessoa, sem compartilhar senhas.
6. **Níveis de permissão:** cada perfil acessa só o que precisa. Por exemplo, só o psicólogo de referência vê a evolução do prontuário do seu paciente.
7. **Backup diário** dos dados, com uma cópia guardada em outro lugar.
8. **Antivírus e atualizações** em todos os computadores.
9. **Registro de acessos (logs)**, para saber quem acessou cada prontuário.
10. **Guarda do prontuário por 5 anos**, como o CFP exige.
11. **Criptografia AES-256** em todos os dados guardados no banco de dados (requisito RNFy).

## Conformidade
- **LGPD:** proteção dos dados pessoais e sensíveis.
- **Resolução CFP nº 010/2005:** sigilo profissional.
